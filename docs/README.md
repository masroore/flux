## Quick Start

### Installation

Flux Pro components are automatically available when you have the package installed.

### Basic Usage

```blade
<flux:button>Click me</flux:button>

<flux:input wire:model="name" placeholder="Enter name" />

<flux:select wire:model="status">
    <option value="active">Active</option>
    <option value="inactive">Inactive</option>
</flux:select>
```

## Key Features

- **Livewire Integration** - Seamless integration with Livewire 3+
- **Dark Mode Support** - All components support dark mode out of the box
- **Accessibility** - Built with accessibility best practices
- **Customizable** - Easily customizable with Tailwind CSS
- **TypeScript** - Full TypeScript support for enhanced development
