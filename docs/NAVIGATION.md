## Component Props Quick Reference

### Common Props Across Components

Most components support these common props:

- `name` - Form field name (string)
- `wire:model` - Livewire data binding
- `placeholder` - Placeholder text (string)
- `disabled` - Disable the component (boolean)
- `invalid` - Mark as invalid (boolean)
- `variant` - Visual style variant (string)
- `size` - Size variant (string: 'sm', 'md', 'lg', 'xl', etc.)
- `class` - Additional CSS classes

### Form-Specific Props

- `clearable` - Show clear button (boolean)
- `searchable` - Enable search (boolean)
- `readonly` - Read-only state (boolean)
- `value` - Component value
- `mode` - Operating mode (varies by component)

### Layout Props

- `position` - Position of floating elements (string: 'top', 'bottom', 'left', 'right', etc.)
- `scrollable` - Enable scrolling (boolean)
- `expanded` - Initially expanded state (boolean)

## Livewire Integration

All form components support Livewire integration:

```blade
<!-- Two-way data binding -->
<flux:select wire:model="status">
    <option value="active">Active</option>
    <option value="inactive">Inactive</option>
</flux:select>

<!-- Live data binding -->
<flux:autocomplete wire:model.live="search" />

<!-- Debounced binding -->
<flux:editor wire:model.debounce.500ms="content" />
```
